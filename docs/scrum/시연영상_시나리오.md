# Rainbow Bridge 시연 영상 시나리오

> 목표 길이: 약 5분
> 목적: 레인보우 브릿지의 핵심 기능을 실제 앱 흐름으로 보여주면서, 보호자가 점차 회복 여정을 따라가는 모습을 전달한다.
> 핵심 메시지: **레인보우 브릿지는 이별을 없애주는 서비스가 아니라, 보호자가 그 과정을 혼자 버티지 않도록 곁에 있어주는 서비스다.**

---

## 0. 영상 전체 구성

| 구간 |        시간 | 내용                      | 목적        |
| -- | --------: | ----------------------- | --------- |
| 1막 | 0:00~0:40 | 보호자와 반려동물 소개, 시한부 선고    | 감정 몰입     |
| 2막 | 0:40~1:30 | 앱 진입, 회원가입, 프로필 등록      | 서비스 시작    |
| 3막 | 1:30~2:20 | 생전 기록 홈, 버킷리스트/일기/사진    | 이별 전 기록   |
| 4막 | 2:20~3:20 | 사후 회복 홈, 감정 체크인, 위기 감지  | 사후 전환     |
| 5막 | 3:20~4:25 | 상태별 미션, 회복 로드맵, 선물함     | 점차 나아짐    |
| 6막 | 4:25~5:10 | 추모 편지, TTS, 영상/GIF, 리포트 | 핵심 기능 임팩트 |
| 7막 | 5:10~5:25 | 클로징 메시지                 | 서비스 철학 정리 |

**보여줄 구성:**

| 상태    | 미션 난이도                  | 예시                          |
| ----- | ----------------------- | --------------------------- |
| L2~L3 | gentle                  | 물 한 잔 마시기, 숨 세 번 쉬기, 창가에 앉기 |
| L1    | gentle + small          | 집 앞 5분 산책, 추억 한 줄 적기        |

**화면 자막:**

```text

```

```text

초기에는 부담이 적은 gentle 미션,
회복이 진행되면 small,
안정 단계에서는 active 미션까지 확장됩니다.
```
