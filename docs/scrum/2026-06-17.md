## 4. 주요 논의

### 4-1. 서버 디스크 관리

- **원인:** uploads/ 고아 파일 + docker 이미지 누적
- **조치:** orphan 파일 삭제 스크립트 실행 + `docker system prune -f`
- **결과:** 22GB 확보, 88% → 40%대
- **재발 방지:** 향후 주기적 prune 또는 업로드 파일 만료 정책 검토 필요

### 4-2. demo03 슬라이드쇼 UTC/KST 버그

- **원인:** 고아 파일 cleanup 시 cutoff를 UTC 기준으로 설정 → KST 당일 업로드 사진도 삭제됨
- **조치:** image/ 폴더 20장 재업로드, slideshow_v2.mp4 재생성
- **교훈:** 서버 시각 기준 UTC 주의 (KST = UTC+9)

### 4-3. demo04 1인칭 편지 파이프라인

- **문제 1:** `first_person` 필드 없는 최신 메시지 → `loadFirstPerson()`이 매번 재생성
  - **해결:** 이후 생성된 3인칭 메시지 5건 삭제 (DB 직접 수정)
- **문제 2:** Qwen3 TTS narration 출력
  - **해결:** 최신 메시지를 first_person=true 레코드로 복원, tone=female로 voiced 생성
- **문제 3:** 추모영상 무음·편지 루프 + BGM이 TTS 음성 묻힘 (#346)
  - **해결:** 무음 버그·루프 제거 + loudnorm 정규화 + 드라이빙 오디오 전처리, BGM 0.7→0.15 축소
- **voiced 생성 흐름:**
  - 로컬에서 LP 서버(`legislation-code-many-uncertainty.trycloudflare.com`) → 494KB MP4
  - Qwen3(`systems-alphabetical-labeled-vegetation.trycloudflare.com`) → 4148KB WAV (처리시간 약 3분)
  - ffmpeg LP+TTS 합성 → voiced_qwen3.mp4 (419KB)
  - SCP 서버 업로드 → docker cp → DB voiced_url 갱신

### 4-4. LP·TTS 성능 지표 (측정값)

| 항목 | 값 | 비고 |
|------|-----|------|
| LP 영상 생성 시간 | 약 111초 | 512×512, 243프레임, cloudflare tunnel |
| Qwen3 TTS 처리 시간 | 약 180~360초 | GPU 정체 시 타임아웃 발생 |
| voiced ffmpeg 합성 | < 1초 | 로컬 |
| voiced 파일 크기 | 419KB | 9.64초 |
