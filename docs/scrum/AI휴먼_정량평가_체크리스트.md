## § 0. 검문소 파이프라인 오케스트레이터

> 매 응답이 나올 때마다 검문소(A~D)를 통과시켜 점수 로그를 남기는 중앙 실행 스크립트.

```
사용자 입력
   ↓
[우리 시스템]
   ↓ 텍스트 응답 ──► (검문소 A) G-Eval Judge     → 대화 점수
   ↓ TTS 음성   ──► (검문소 B) Whisper STT       → CER/WER
   ↓ 립싱크 영상 ──► (검문소 C) corr/lag          → 립싱크 상관계수/지연
   ↓
사용자 화면   ────► (검문소 D) 서버 로그          → TTFB / FPS / 완료율
```

## § 2. 시스템 지표 (검문소 D) — TTFB · FPS · 완료율

### 2-1. TTFB (응답 첫 바이트까지 걸린 시간)

> 목표: 대화형 **1.5초 이내**

```python
t_end = time.time()
stream = call_engine(user_text)
first = next(stream)
ttfb = time.time() - t_end
log_metric(ttfb=ttfb)
```

| 항목 | 위치 | 담당 | 상태 |
|------|------|------|------|
| 백엔드 TTFB 로깅 추가 | `backend/app/middleware/` 또는 LLM 호출부 | 세종/윤한님께 부탁 | ⬜ 미시작 |

### 2-2. FPS (영상 초당 프레임 수)

> 목표: **30fps 이상** 유지율

```python
fps = frame_count / elapsed_sec
```

| 항목 | 위치 | 담당 | 상태 |
|------|------|------|------|
| 영상 플레이어 FPS 측정 | `frontend-rn/` 플레이어 컴포넌트 또는 LP 렌더러 | 민경이님 / 장민수님께 부탁 | ⬜ 미시작 |

### 2-3. Task Completion Rate (완료율)

> 완료율(%) = (끝까지 완료된 세션 수 / 전체 세션 수) × 100
> 세션 시작/정상종료 이벤트를 DB에 남기고 집계

| 항목 | 위치 | 담당 | 상태 |
|------|------|------|------|
| 세션 시작/종료 이벤트 DB 저장 | `backend/app/` | 세종/윤한님께 부탁 | ⬜ 미시작 |
| 완료율 집계 쿼리/스크립트 | `backend/` | 세종/윤한님께 부탁 | ⬜ 미시작 |

## § 3. 대화 품질 (검문소 A) — G-Eval

> LLM을 채점관으로 사용해 1~5점 자동 채점.

### 채점 프롬프트 (루브릭)

```text
당신은 엄격한 대화 평가관입니다. 아래 기준으로 1~5점 채점하세요.

[평가 항목]
- 퍼르소나 일관성: 설정된 말투/성격을 유지하는가
- 유용성: 사용자 의도를 해결하는가
- 자연스러움: 사람과 대화하는 느낌인가

[채점 규칙]
1점=전혀 아님 ... 5점=완벽. 근거를 1문장으로 먼저 쓰고 점수를 낸다.

JSON으로만 출력:
{"reason":"...", "consistency":n, "usefulness":n, "naturalness":n}
```

> 팁: 같은 응답을 3번 채점해 평균 → 신뢰도 ↑

### 자동 채점 코드

```python
scores = [g_eval(PERSONA, t["input"], run_our_system(t["input"])) for t in testset]
avg = sum(s["consistency"] for s in scores) / len(scores)
```

| 항목 | 파일 | 담당 | 상태 |
|------|------|------|------|
| G-Eval 채점 스크립트 작성 | `ai/llm/g_eval.py` | 반소람 | ✅ 완료 |
| G-Eval 실행 (40케이스 × 3회) | `geval_results_v7.json` | 반소람 | ✅ 완료 (2026-06-16) |

## § 4. 음성 품질 (검문소 B) — CER / WER

> TTS 음성을 Whisper로 받아쓰기 → 원문과 비교. **한국어는 CER 주력.**

### 설치

```bash
pip install openai-whisper jiwer
# 또는 현재 사용 중인 faster-whisper
```

### 측정 코드

```python
model = whisper.load_model("large-v3")

def speech_score(audio_path, original_text):
    heard = model.transcribe(audio_path, language="ko")["text"]
    return {
        "CER": cer(original_text, heard),   # 주력, 0에 가까울수록 좋음
        "WER": wer(original_text, heard),   # 보조
    }
```

> MCD(음색 왜곡)는 원본 목소리가 있어야 측정 가능 → 생략 가능.

| 항목 | 파일 | 담당 | 상태 |
|------|------|------|------|
| CER 측정 스크립트 | `ai/tts/analyze_stt.py` | 정환주님 | ✅ 구현 완료 (TTS 비교용) |
| 평가 testset 음성 파일에 연동 | — | 정환주님께 부탁 | ✅ 완료 (CER 1.0%/5.5%, WER 3.8%/19.1% — 3인칭/1인칭) |

## § 5. 립싱크 (검문소 C) — corr / lag (동물 아바타 기준)

> SyncNet은 사람 얼굴 기반 모델 → 동물 아바타에 적용 불가 (5-B 해당).
> 대신 **입 벌림 값 ↔ 오디오 음량(RMS) 상관계수/지연**으로 측정.

> - **corr (상관계수): 1에 가까울수록 좋음** — 목표 ≥ 0.7
> - **lag (지연): 0에 가까울수록 좋음** — 목표 ±100ms 이내

| 항목 | 위치 | 담당 | 상태 |
|------|------|------|------|
| corr/lag 측정 | — | 정환주님 | ✅ 완료 (corr 0.896, lag +40ms) |

## § 6. MOS (사람 평가) — 자동점수의 "정답지"

> 자동 점수가 사람 느낌과 같은 방향인지 교차검증. **5~10명이면 됨.**

- 구글폼으로 항목별 **1~5점**: 음성 자연스러움 / 영상 자연스러움 / 대화 만족도
- 같은 응답 5~10개를 순서 없이 평가 → 평균 = MOS
- 자동 점수와 **평가자 일치도 먼저 확인**

| 항목 | 위치 | 담당 | 상태 |
|------|------|------|------|
| 구글폼 설계 (음성/영상/대화 1~5점) | 구글폼 | 반소람 or 전체 | ❌ 폐기 |
| 팀원/지인 5~10명 평가 진행 | — | 전체 | ❌ 폐기 |

|---------|------------|
| 텍스트 챗봇 | G-Eval + TTFB + 완료율 |
| + 음성 (TTS) | 위 + CER |
| + 영상 (립싱크) | 위 + LSE-C/D + FPS |
| 전체 AI휴먼 | 위 전부 + MOS 교차검증 |
